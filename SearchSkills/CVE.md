**Common Vulnerabilities and Exposures (CVE)** shows known vulnerabilities using IDs in the format CVE-YEAR-NUMBER, but if a vulnerability is very famous, it can also have a nickname. CVE scores each vulnerability based on its impact, complexity, and availability, helping organizations prioritize risks to prevent and fix the most important issues.

## :rotating_light: Scenario description
Access the CVE to analyze a vulnerability and its score, as well as the affected products.

## :detective: Investigation step-by-step
### Step 1
Search the CVE for the mentioned vulnerability code.

### Step 2
Find the score and analyze other details like exploitability, impact, and solution.

## :shield: Conclusion 
Using a CVE helps identify known security flaws in software and hardware, making it easier to protect data from known attacks based on each vulnerability.
